# The RW seams sprawl on their own

- `sprawl(s, scope)`: pieces on RW lots count only the pieces on RW lots, so a big home RT no longer makes the Balai RW, Posyandu and Portal 3x dearer. RW 2★ comes 3 to 11 min sooner for the slow types; scorecard row 10 goes from 27 misses to 4.
- Scorecard bots build a combo piece's required building (Balai RW) first; `RunOpts.onTick` lets a probe read the state each tick.
