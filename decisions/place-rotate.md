# Rotate while placing

- The floating Place bar gets a Rotate button between Cancel and Place (`#place-rot`, text `insp.rotate`, the same word as the inspector's).
- It mirrors the ghost, as turning a placed building does (`rot` 1). The placed building keeps that facing; a building being moved starts with its own facing and keeps the new one.
- Paths have no facing, so the button is hidden while laying one.
