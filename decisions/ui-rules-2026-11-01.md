# UI rules from Hari's feedback, 2026-11-01

Approved by Hari ("ok"), 2026-11-01. Added to UI.md.

- Rule 5: no ellipsis exceptions. The goal pill and Combo card clamps are now known fails.
- Rule 10: no Skip anywhere (matches #220); only the named control takes taps during a step.
- Rule 13: the one-primary limit moves to rule 14.
- New 14: primary, secondary, choice and input each have their own look.
- New 15: one tab set holds one kind of thing; collections open from a header button.
- New 16: pills, chips and buttons use 6 words or fewer, lead with a verb or plain label, detail on tap.
- New 17: map art stays in its footprint.

Sources: today's feedback on the Combo tab in Build, the cut goal pill, the Wacana sheet, the setup screen, the tutorial Skip, and the crane box over the road (#221).

Against: dropping the Combo clamp means some combo effects need rewriting; 6 words is a judgement call.

Effect on docs/plans/ui-hierarchy.md: rule 14 is now in UI.md, so T1 only changes the CSS.
