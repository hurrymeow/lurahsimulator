# The RT 3★ stall on seed 4 is a bot gap, not a balance gap

## Finding
The builder and the honest bot never reached RT 3★ on seed 4. The shopkeeper, safety and hint bots reached it on the same seed (weeks 98 to 109). So the game does not lock that seed.

The builder sat on Rp 3 billion with Popularitas near 22, and only two Pos Ronda. Its map had no free site beside a path, so it could not place a third. Residents kept arriving and each one drains Popularitas, so the 65 needed for the star drifted out of reach. The first flood (week 78) also cost 13 at the moment the bot crossed 55 residents.

## Call: change the bot, not the game
When Popularitas is the only goal left for the star, the bot now builds Pos Ronda beyond its usual few (the data allows 8). If the map is full, it swaps a Sawah for one.

Why this and not a game change:
- A player has this move. Pos Ronda is the main Popularitas building and the star line names Popularitas.
- Other bot styles pass the seed, so the 65 bar and the 0.14 expectation drain are not the cause.

Counter-argument: a full RT with Rp 3 billion and no way to add Popularitas is still a dead end for a person who has not found the swap. The game never tells a player that a Sawah can make room. This is logged in TODO as a hint question (what does the Popularitas goal say to do when the map is full?) rather than fixed with a number.

Not chosen: lowering the 65 (the seed would need under 25, so it would not help), a late Popularitas sink (content, belongs with the Act 2 plan).

## Result
RT 3★ week, seeds 1 to 10, bots builder, honest, shopkeeper, safety and hint: reached on 50 of 50 runs. Before: 48 of 50. Seeds that already passed are unchanged to the week, since the rule fires only when Popularitas is the sole open goal.
