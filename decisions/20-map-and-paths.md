# Map size and paths (PR 20)

- **Bigger map:** the grid grew from 9x13 to 13x17 (221 tiles, up from 117). The map already pans, so phone width does not limit it: tiles stay 64x32 at 320px. Save version 2 shifts v1 buildings by +2,+2 so the village stays centred and keeps its layout. Ring road, fields and sea follow the grid size, so the new edge keeps its scenery.
- **Jalan Setapak (free path):** costs Rp 0, builds at once, has no upkeep and takes a tile. A working building with income beside a path (4-way) earns +10% once, however many paths touch it. The number is `pathIncome` on the jalan entry in `src/data/buildings.ts`. The trade is a tile you could have built on, and a bonus that only matters for shops. Paths are not counted in ranking score or hit by banjir, so free tiles cannot farm score. Walkers pay 2.5 per step on open ground against 1 on a path, so they detour onto paths. Paths can be removed from the tile inspector, with no refund. Placing a path keeps placement mode on, to paint several tiles.
