# Tutorial: no Skip, taps locked to the step

- The opener has no Skip button. The only button is "Got it" on the last note.
- While a step names a control (Build, Housing tab, Rumah card, map tile, Place bar), taps elsewhere are swallowed.
- Never locked: the coach note, event pop-ups (`#modal`), the welcome, the last note. Cancel stays in the Place bar, so no step can trap the player.
