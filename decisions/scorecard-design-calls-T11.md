# T11: item 18 compares rolled options on average

Item 18 used to skip advice choices with `outcomes`, so the row could only read Unknown. It now includes them and gives each the probability-weighted mean of its `res` changes (branch weights divided by their sum, with any top-level `res` added to every branch), then runs the same price-vector dominance test as fixed results. Only the four `Resources` keys (`rupiah`, `sabar`, `orangDalam`, `viral`) are compared; `incomePct`, `stamp`, `cleanAudit` and `perWacana` are not resources and stay out of the vector, as do options with `special`, `modifier` or a top-level `incomePct`, which the check already skipped. A dominated option is named in the evidence as `<event>#<choice> "<label>"`, and the row reads Pass or Fail instead of being forced to Unknown. Event data was not changed, so any real dominance the mean exposes is reported, not fixed.
