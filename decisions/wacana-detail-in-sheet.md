# Wacana detail lives in the sheet

Date: 2026-11-01. Part of decisions/ui-hierarchy.md.

The plan said "pop-up". The Wacana detail is a second view in the same bottom sheet, with a back button, so it is still two levels (list, then detail). The tap-to-dismiss modal cannot hold buttons that stay open after Umumkan, and the Back key already closes the sheet. Layout still follows rule 8: title, body, labelled columns, buttons at the bottom.
