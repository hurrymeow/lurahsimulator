# Short menu labels

Hari asked for shorter menu labels (TODO items 9 and 10) so they fit at 320px.

| Where | Before (ID / EN) | After (ID / EN) |
|---|---|---|
| Menu tile, treasury and ranking panel | Kas & peringkat / Treasury & ranking | Peringkat / Ranking |
| Menu tile, combo list | Buku Combo / Combo Book | Combo / Combo |

"Kas" is dropped from the ID label, so the panel is named for its ranking. Code ids (`menu.stats`, `menu.combo`, `act-combo`) are unchanged. The docs that name the in-game list (GAME-DESIGN.md, UI.md, ART.md) now say "Combo", so they match the game.
