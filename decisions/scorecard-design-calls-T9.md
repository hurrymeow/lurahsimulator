# Scorecard row 8: hindsight horizons (T9)

Item 8 now reads its verdict from the timeline instead of staying Unknown. A builder tick after minute 2 passes the short horizon when a `goal` event (a checklist line met) falls within the next 2 min, and the mid horizon when a `star`, `sk` or Lomba falls within the next 15 min; the row passes when both hold on at least 90% of ticks (GAME-DESIGN.md §8). The Lomba was not in the timeline, so `driver.ts` now records a `lomba` event on the Agustusan day (held, or skipped when the bot picked no contests). For the long horizon the Emas bar is Sejahtera (`decisions/goal-inem-pressure.md`), which the row already stores, so no new row field was needed; it must change at least once between consecutive stop points, using the star/promote/report stop set that item 7 already uses.
